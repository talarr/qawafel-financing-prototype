# Qawafel SME Financing Readiness Prototype

## What It Does
This prototype helps illustrate how a Saudi SME wholesaler can review invoice data before preparing a financing package. It displays 12 months of sample sales, invoice counts, paid-invoice percentage, monthly sales, and basic data-quality checks. Users can preview invoices and download the sample invoice data as a CSV file.

## How to Open or Run It
1. Open the live demo: https://talarr.github.io/qawafel-financing-prototype/
2. Alternatively, download this repository and open `index.html` in a modern web browser.
3. No installation, server, or API key is required.

## Sample Data
The fictional invoice records are embedded in `index.html`. The prototype covers October 2025 through September 2026. Users can download the sample invoice records using the CSV download button.

## Assumptions and Limitations
- All business names, invoice records, amounts, and statuses are fictional.
- The prototype assumes invoice data has already been extracted from an Excel file.
- Bank statement data is not included, so invoice-to-bank reconciliation is not performed.
- Data-quality checks are illustrative and do not replace full validation or human review.
- No real bank API is connected.
- The status "Ready for analyst review" does not mean financing is approved.
- The bank makes the final financing decision.

## AI Tools Used
ChatGPT was used to assist with drafting the prototype code, sample data logic, and this README. All displayed data is fictional.
